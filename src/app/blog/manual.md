# 📝 블로그 포스트 작성 매뉴얼 (Blog Post Manual)

이 블로그는 `src/data/posts.ts` 파일의 데이터를 기반으로 목록을 생성하고 상세 페이지를 보여줍니다. 새로운 글을 추가하려면 아래 절차를 따라주세요.

## 1. 파일 위치
- 데이터 파일: `src/data/posts.ts`

## 2. 작성 방법
`posts` 배열 안에 새로운 객체 `{ ... }`를 추가합니다. 최신글이 가장 먼저 보이게 하려면 배열의 앞쪽에 추가하거나 날짜 형식을 맞춰주세요.

### 코드 예시
```typescript
{
  id: 'unique-id-1',          // URL 주소가 될 고유 아이디 (영문/숫자 권장)
  title: '포스트 제목',         // 블로그 목록과 상세 페이지에 표시될 제목
  summary: '포스트 요약 내용',   // 목록에서 보여줄 짧은 설명
  date: '2026.06.05',         // 작성 날짜 (YYYY.MM.DD 형식 권장)
  tags: ['Tech', 'Life'],     // 적용할 태그 (미리 정의된 색상이 자동 적용됨)
}
```

## 3. 사용 가능한 태그 (Tags)
현재 디자인 시스템에 등록된 태그와 색상은 다음과 같습니다. 이 외의 태그를 입력하면 기본 회색으로 표시됩니다.
- `Tech`: 하늘색
- `Food`: 주황색
- `Design`: 보라색
- `Life`: 초록색
- `Project`: 인디고(진보라)

## 4. 상세 내용 수정
현재 블로그 상세 페이지(`src/app/blog/[id]/page.tsx`)는 샘플 텍스트를 보여주고 있습니다. 각 글마다 다른 상세 내용을 넣으려면:
1. `posts.ts`의 데이터 구조에 `content` 필드를 추가합니다.
2. 상세 페이지 파일에서 `post.content`를 렌더링하도록 수정합니다.
*(추후 Markdown 파일을 직접 읽어오는 방식으로 고도화할 수 있습니다.)*

---
**Tip:** `id`는 나중에 `blog/unique-id-1`과 같이 접속 주소가 되므로, 중복되지 않게 설정해 주세요!
